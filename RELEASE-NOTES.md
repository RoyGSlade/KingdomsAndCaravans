# Kingdoms & Caravans 0.2.1

## Early friend playtest

This build is an unfinished, unsigned Windows x64 prototype shared for friendly playtesting. It is a small survival RTS slice with one map, physical construction and hauling, food needs, housing, workers, swordsmen, archers, and two raider waves.

The main playtest question is simple: after the first wave, can you name two useful investments and pursue one? The goal is to learn whether the city’s choices and shortages are understandable, not to present a finished game.

## Playtest reminders

- Extract the full ZIP before launching the executable.
- Keep a staffed farm and watch food reserves.
- Build a woodcutter and sawmill to make more planks.
- Houses add room for civilians, but arrivals need spare food and a staffed farm.
- Version 0.2 saves use `kingdom-city-v2.json`; version 0.1 saves cannot load in this build.
- The update flow keeps the current install and save in place by downloading the new version to a separate folder, then lets you choose when to restart.

Please expect bugs, rough balance, and unfinished presentation. Feedback about the first wave, confusing shortages, idle time, and whether you wanted to continue is especially useful.

## New in 0.2.1

The menu now includes Check for updates, verified download progress, cancellation,
and Save/Restart with update. New versions install alongside the current build
and keep version-2 saves. The game remains playable offline.

Validation: 130 simulation checks, 41 gameplay UI checks, 38 updater package checks,
and 12 updater UI checks passed locally. The exported Windows build launched
successfully on the development laptop. Other PCs remain a playtest question.
